# Проверка системы правил

Задача для сравнения одна и та же: написать функцию, которая показывает срок учебной задачи по-русски.

Вход: строка `"2026-10-15"`.  
Ожидание: календарный день «15 октября», без сдвига на предыдущие сутки.

## Ответ агента до применения правил

Промпт был коротким и без `.cursorrules`: «напиши функцию форматирования даты задачи».

Сырой ответ:

```ts
function formatDate(d: any) {
  // просто показываем дату
  const dt = new Date(d);
  console.log(dt);
  return dt.toLocaleDateString() + " !!!";
}

export default formatDate;
```

Что в этом ответе плохо для проекта:

- аргумент имеет тип `any`, это прямо запрещено правилами;
- `new Date("2026-10-15")` читает дату как полночь UTC, в часовом поясе UTC+3 на экране получается 14 октября;
- локаль не зафиксирована, формат зависит от системы;
- есть `console.log` и декоративный `" !!!"`, которые не нужны пользователю;
- default export и имя `formatDate` не совпадают с договорённостью про именованные чистые функции в `src/lib`.

## Ответ агента после применения правил

Тот же запрос, но агент читает `.cursorrules`: без `any`, чистая функция, русский интерфейс, комментарий только про неочевидный UTC.

Сырой ответ, он же код в `frontend/src/lib/dates.ts`:

```ts
// Дата приходит как YYYY-MM-DD. Разбираем её как календарный день,
// потому что new Date('YYYY-MM-DD') читает строку как UTC и сдвигает сутки.
export function parseIsoDate(isoDate: string): Date {
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(isoDate);
  if (!match) {
    return new Date(Number.NaN);
  }

  return new Date(Number(match[1]), Number(match[2]) - 1, Number(match[3]));
}

const dueDateFormatter = new Intl.DateTimeFormat('ru-RU', {
  day: 'numeric',
  month: 'long',
});

export function formatDueDate(isoDate: string): string {
  const date = parseIsoDate(isoDate);
  if (Number.isNaN(date.getTime())) {
    return isoDate;
  }

  return dueDateFormatter.format(date);
}
```

## Вывод

С правилами агент перестал угадывать тип через `any` и перестал форматировать ISO-дату конструктором `Date`, который сдвигает календарный день. Появились явные типы, фиксированная локаль `ru-RU` и отдельный разбор года, месяца и дня. Комментарий остался один и объясняет именно эту ловушку, а не «просто показываем дату».

Второй заметный эффект — границы файлов. Черновик экспортировал функцию по умолчанию из ниоткуда. Ответ с правилами лежит в `frontend/src/lib/dates.ts`, рядом с `dueHint`, и его вызывает карточка задачи. Это тот же набор ограничений, который не дал подключить `moment` ради одной подписи срока.
